# GoZone Frontend — Assets

Place the following image files in this folder:

- `icon.png` — App icon (1024x1024)
- `splash.png` — Splash screen logo (centered on green background)
- `adaptive-icon.png` — Android adaptive icon (1024x1024)
- `favicon.png` — Web favicon (48x48)

For now, Expo will use a default icon if these aren't present.
We'll add proper branding assets later.
